Rows list

data · rows-list · minimal

Four records, set four ways. Rows are separated by space and the distance between them, not by lines; the hover fill bleeds one inset past the text so a row reads as a region without an edge. Metadata recedes by colour and weight, numerals are tabular, and each row is one control that hovers, takes a visible focus ring, presses and disables.

Index list

Mono index, name, one line, a metadata word or two Hover or tab to a row and the activation bar lights. Each row stores a coordinate in data-x and data-y (0 to 1); when window.ActivationField exists on the page, the row calls activate(x, y, 1, 600) so a host field can fire at that point.

Resolving log

Corner-bracket marker, name, one line, a key-value column with a signal meter Class and status decode from glyphs to text once, the first time a row enters view, over eighteen frames; the name never scrambles, and the corners pull in as the meter lights. Under reduced motion every row arrives resolved. The last row carries the file's one status dot: its reading is taken by the page itself.

Editorial index

Numeral, serif title, one sentence, a small metadata line Hover indents the row by 6px and colours the numeral. The accent appears here and on the live row only, so it keeps meaning state.

Typographic index

Large numeral, big name, a dry line, a status word Hover shifts the name from medium to bold. The withdrawn row is disabled: its ink drops to the metadata rung and nothing shifts.
