How it holds up

Material

backdrop-filter: blur() saturate() over a semi-transparent tint, a hairline border, a two-stop shadow and a top highlight. The saturate step restores the colour the blur washes out.

Contrast, bought with tint

The label reads at full strength because the tint alpha is raised, not because the backdrop is darkened. The primary tint stays opaque enough to clear 4.5:1 over any backdrop region.

Fallbacks

Without backdrop-filter the base rule serves an opaque tinted surface. Under prefers-reduced-transparency the blur is dropped and the same opaque fill takes over.

Motion

The filter is never animated. Only transform, background-color and box-shadow transition, and prefers-reduced-motion stills them and slows the loading spinner.

Colour

Every ink and fill is an alpha colour, never the CSS opacity property, so a dimmed state does not fade the text and spinner with it.

Keyboard

Real <button> elements throughout. Focus-visible draws a two-pixel ring with offset; a pointer press alone does not.
