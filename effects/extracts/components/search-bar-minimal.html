Search bar

A hairline field on the canvas with a leading icon at reduced ink, a clear control that appears with content, and a focus ring that thickens the border rather than recolouring it. Every state and size below is rendered from one component.

Live

A working instance. Type to reveal the clear control, submit to see the brief loading state, and tab to it to check the focus ring.

States

The full checklist, each forced so the sheet documents itself. Hover and pressed also occur live on the instance above.

Default

Resting field, placeholder at tertiary ink.

Hover

Fill lifts one rung, border strengthens.

Focus-visible

Border goes solid, a neutral ring is added.

Pressed

Momentary darker fill on pointer-down.

Disabled

Muted panel fill, no ring, not focusable.

Loading

Leading icon becomes a spinner while a query runs.

Sizes

Three heights on the 8px rhythm. Icon, type size, and radius scale with the field so proportion holds.

Small · 36px

Dense toolbars and filter rows.

Medium · 44px

The default, a comfortable touch target.

Large · 52px

Page-level or hero search.
