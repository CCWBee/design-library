Search bar

A frosted search field for placing over imagery or a busy background. The blur removes contrast, so a translucent tint carries the type back to a legible floor and the icon and caret sit at reduced ink. Each field below rests on a coloured backdrop so the frosting is honest; the page itself stays neutral.

States

The full state checklist for this input type: default, hover, focus-visible, pressed submit, disabled and loading. The default field is live; try typing, tabbing to it, or pressing submit. The others are pinned so each reads at a glance.

Default
Live. Resting tint, hairline edge, soft layered shadow.
Hover
Shadow deepens to lift the surface a touch. No colour shift.
Focus-visible
Accent border and a 3px ring. Clear button appears once there is text.
Pressed
Submit dips by 1px and darkens on activation.
Disabled
Frosting drops to a flat muted fill; controls read as inert.
Loading
Searching
Spinner takes the icon slot while results resolve. Rests still under reduced motion.

Sizes

Three heights for different densities: small for a toolbar, medium as the default, large for a hero or empty-state search. Radius and type scale with the height.

Glass register, inputs family. Frosting via backdrop-filter: blur() saturate() with a tinted readability floor, a 1px top-edge highlight and a layered shadow. Falls back to an opaque tinted surface where backdrop-filter is unsupported or where prefers-reduced-transparency is set, and holds still under prefers-reduced-motion. Light and dark carried entirely by tokens. Ink and fills use alpha colours throughout, never the opacity property.
