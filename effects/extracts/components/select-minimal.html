Select · minimal

A single-select dropdown in the minimal register. Hairline trigger on the canvas, an opaque menu that keeps page content readable behind it, hierarchy from size and space rather than lines.

Ontology cell: inputs / select / minimal

Live control

Fully interactive. Open with click, or with Enter, Space, or the down arrow when focused. Move with the arrow keys, choose with Enter, dismiss with Escape. Focus returns to the trigger on close.

Menu and option states

The open listbox is the defining surface of the control. Its background is an opaque elevated token so page content never ghosts through, which is also the answer for reduced transparency. One soft single-layer shadow earns its place here because the menu genuinely floats above the page.
